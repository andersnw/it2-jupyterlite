# IT2 i nettleseren

Notebookene fra IT2, klare til bruk i nettleseren med JupyterLite. Du trenger ikke installere noe.

## Viktig å vite

- Arbeidet ditt lagres bare i nettleseren du bruker. Bytter du PC eller nettleser, eller sletter nettleserdata, er det borte.
- Last ned notebooken (høyreklikk på filen → Download) når du skal levere eller ta vare på noe.
